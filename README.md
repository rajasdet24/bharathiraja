# bharathiraja

The main purpose of this framework which is created for Interview purpose.

I have created framework from the scratch to automated American express application and its related scenarios.

I have used the below tools & technologies to create the framework,

1. Selenium
2. Java
3. Data Driven Framework with Parameters
4. POM Design pattern (Page class & Test Class)
5. Log4J
6. TestNG
7. Maven
8. Cross Browser Testing (Chrome & Safari)
